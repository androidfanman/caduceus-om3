# webapp

LookLab, Vite/TypeScript browser app, source for built `looklab/`. Build: `make build-webapp`, publish: `make looklab`. `README.md` features. `Dockerfile`, `nginx.conf` container serve. `vite.config.ts`, `index.html`. `public/fonts/` label font for name pictures. `public/samples/` sample photos, credits in `CREDITS.md`.

## Subdirectories

- [`scripts/`](scripts/CLAUDE.md) — film and library generators
- [`src/`](src/CLAUDE.md) — app source

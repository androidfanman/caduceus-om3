# webapp

LookLab, Vite/TypeScript browser app, source for built `looklab/`. Build: `make build-webapp`, publish: `make looklab`. `README.md` features. `Dockerfile`, `nginx.conf` container serve. `vite.config.ts`, `index.html`.

## Subdirectories

- [`public/fonts/`](public/fonts/CLAUDE.md) — label font for name pictures
- [`public/samples/`](public/samples/CLAUDE.md) — sample photos and credits
- [`scripts/`](scripts/CLAUDE.md) — film and library generators
- [`src/`](src/CLAUDE.md) — app source

# looklab

Built LookLab web app, served on GitHub Pages. Generated from `webapp/` by `make looklab`. Never hand-edit. Owner approves new or changed images before publishing. `index.html` CSP allows self only.

## Subdirectories

- [`assets/`](assets/CLAUDE.md) — built JS, CSS and font files
- [`fonts/`](fonts/CLAUDE.md) — OM3 Label font and license
- [`samples/`](samples/CLAUDE.md) — public-domain sample photos and credits

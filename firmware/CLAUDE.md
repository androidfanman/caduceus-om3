# firmware

Patch build and patcher. `build.py` developer build from official 1.1 firmware, `patch.py` user-facing patcher applying `releases/vX/patch.json`, `VERSION`. Helper generators: `crop.py`, `halation.py`, `shading.py`, `photocode.py`, `frames.py`, `diagrams.py`, `mkicons.py`, `rgbpics.py`. `oe_container.py` OE container decoder, `provenance.py` source hashing.

## Subdirectories

- [`src/`](src/CLAUDE.md) — assembly and linker script

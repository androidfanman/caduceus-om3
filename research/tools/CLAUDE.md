# tools

Firmware analysis tools: `oe_decode.py` decodes firmware container, `sections.py` lists sections and free tails, `check_anchors.py` checks anchor addresses, `dis.sh START STOP` disassembles main block. Read-only.

## Subdirectories

- [`parity/`](parity/CLAUDE.md) — E-P7 vs OM-3 parity table builder

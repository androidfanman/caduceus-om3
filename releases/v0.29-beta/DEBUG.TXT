Caduceus for OM-3: debug log switch (optional, v0.27 and later)

While this file is in the OM3MOD folder on the card, the camera writes a plain-text report,
OM3MOD/CADLOG.TXT, at each shutter-button event: the firmware build, which card files loaded and
whether they match the firmware, the picture mode and film, the last save result and the last 32 events.
Attach CADLOG.TXT to a bug report if you are asked for it.

To turn the log off, delete this file from the card. Its contents do not matter.

# releases

One folder per published version: `patch.json`, card files (`GUIDES.BIN`, `LABELS.BIN`, `LOOKS.BIN`, `TONES.BIN`, `CURVES.BIN`), `SHA256SUMS`, `NOTES.md`. Pushing a new folder to `main` publishes a GitHub release. Optional extras (`DEBUG.TXT`, photo code kit zip) are attached, never copied to the card.
